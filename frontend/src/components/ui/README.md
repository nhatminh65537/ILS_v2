## `src/components/ui/`

Shadcn UI auto-generated components. **Do not manually edit.**

To add component: `npx shadcn@latest add <component-name>`

Installed components:
- button, input, label, card, badge
- dialog, sheet, dropdown-menu, separator
- sonner (toast), table
- avatar, skeleton, tabs, alert

Notes:
- `form` in current preset is a recipe and may not generate `form.tsx` automatically.
- Use the installed primitives (`input`, `label`, `button`) with local form state or React Hook Form when needed.
